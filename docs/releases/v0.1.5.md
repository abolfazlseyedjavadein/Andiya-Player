## What's new

- **Studio Noir design:** a new charcoal-and-mint default theme, consistent line
  icons, clearer typography, a redesigned welcome screen, and matching Workspace
  controls. Existing themes remain available.
- **Natural voices at different speeds:** pitch-preserving time stretching keeps
  voices at their original pitch while changing playback speed. Normal-speed
  audio stays byte exact, and the 200% volume boost remains available.
- **Closable library panels:** click Library, History, or Playlist again to close
  the active panel, or use its new close button.
- **Compact playback controls:** core controls remain visible in narrow windows;
  secondary playlist and seeking actions move into the More menu.

## Fixes

- Retain and retry partial audio writes instead of dropping samples.
- Report native filter processing failures and invalid output; filtered exports
  stop instead of silently saving unfiltered frames.
- Prevent callbacks from retired export decoders from restarting playback or
  crashing the next export item.
- Clear playlist selection when manually opening unrelated media, while retaining
  automatic advancement for playlist playback.
- Refresh the newest paused frame after a slow filter finishes.

## Verification and downloads

The release workflow builds, verifies, and packages each platform before publishing
its downloads and SHA-256 sidecars. Regression checks cover audio duration and pitch
from 0.25x to 4x, partial writes, filter failures, export transitions, playlist
selection, slow previews, panel closing, and nine UI snapshots.

- **Windows x64:** portable ZIP and per-user `-setup.exe` installer. Binaries are unsigned.
- **macOS Apple Silicon:** ad-hoc signed DMG; Developer ID signing and notarization are not included.
- **Linux x86_64:** TAR.GZ and DEB packages, with a glibc 2.35+ baseline.

Python filters require a separately installed Python 3 interpreter. Secure stream
profile storage and publisher signature verification remain Windows-only. Andiya
remains MIT licensed; the pitch processor's MIT dependency notices are included.
