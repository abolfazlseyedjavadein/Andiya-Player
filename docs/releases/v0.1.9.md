## Playback and plugins

- Live filtered playback lowers preview resolution when filters fall behind.
  Compare mode uses the same playback pipeline and shows matching original and
  filtered frames. Paused comparisons and exports use decoded resolution.
- The stream address is visible in the Open network stream dialog and the
  Workspace stream editor. Saved Windows stream profiles use encryption.
- Python filters use a verified Python 3.9 or newer interpreter. The Tools panel
  shows errors when a filter worker cannot start or process the preview.
- Restore removed bundled filters, including Soft Contrast, from
  **Tools → Install plugin**. Turn on the restored filter to approve and use it.

## Downloads

- **Windows x64** offers a per-user installer and a portable ZIP. The installer
  is unsigned, so Windows SmartScreen may display a warning.
- **macOS Apple Silicon** offers an ad-hoc signed DMG.
- **Linux x86_64** offers a TAR.GZ archive and a DEB package.

SHA-256 checksums accompany the downloads.
