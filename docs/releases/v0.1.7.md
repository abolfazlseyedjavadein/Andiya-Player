## Plugin settings and drawing tools

- Open a plugin's **Settings** from its card in **Tools**. The popup shares
  parameter values with **Workspace → Filters**.
- Plugins can declare a drawable rectangle in their manifest. Draw, move, or
  resize it on an image or video, then apply all four coordinates together.
  The included Redaction Blur example shows how to use this feature.
- Use **Remove** on any plugin card, including bundled filters. User-installed
  plugins also have their local files and rollback copy removed.
- The developer documentation now includes a worked example and a Word guide
  for adding the settings popup and rectangle tool to a Python filter.

## Downloads

- **Windows x64** offers a per-user installer and a portable ZIP.
- **macOS Apple Silicon** offers an ad-hoc signed DMG.
- **Linux x86_64** offers a TAR.GZ archive and a DEB package.

SHA-256 checksums accompany the downloads.
