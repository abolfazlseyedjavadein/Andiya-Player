## Plugin actions

- Python plugins can declare Settings buttons in `plugin.json` and route
  their IDs through one `on_action` callback. A button can return parameter
  changes, and a rectangle action can return preview coordinates during a drag.
- Redaction Blur 1.3.0 uses this API for **Draw rectangle** and **Reset
  rectangle**. Its Python worker handles drawing, moving, and resizing.
  Reset restores the default box while keeping the current blur radius.
- The rectangle editor uses a bright yellow outline with a dark edge and
  a matching resize handle.
- The user guide, plugin reference, tutorial, and Word guide cover the
  settings and action API. The release bundles the runnable example.

## Downloads

- **Windows x64** offers a per-user installer and a portable ZIP.
- **macOS Apple Silicon** offers an ad-hoc signed DMG.
- **Linux x86_64** offers a TAR.GZ archive and a DEB package.

SHA-256 checksums accompany the downloads.
